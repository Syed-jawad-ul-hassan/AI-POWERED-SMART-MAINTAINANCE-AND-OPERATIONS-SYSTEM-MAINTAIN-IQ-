# MaintainIQ

## AI-Powered Smart Maintenance & Operations System

MaintainIQ is an AI-powered maintenance system that helps organizations manage equipment, maintenance issues, work orders, and maintenance records.

It combines **Generative AI, RAG, and Agentic AI** to analyze maintenance issues, retrieve information from technical documents, and provide actionable recommendations.

### ✨ Features

* 🏭 Equipment management
* 🛠️ Maintenance issue reporting
* 🤖 AI-powered issue triage
* 📚 RAG-based Knowledge Assistant
* 🔄 AI agent workflows
* 📋 Work order management
* 📝 Maintenance records
* 📊 Maintenance dashboard and reports

### 🧰 Tech Stack

**Python · Streamlit · SQLite · Groq · LangChain · ChromaDB · Sentence Transformers · PyMuPDF · LangGraph · Pandas · Matplotlib**
